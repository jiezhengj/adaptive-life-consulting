# Adaptive Life Consulting

很多人会拿 ChatGPT、DeepSeek、豆包之类的 AI 聊生活：要不要换工作、学什么运动、该不该搬家、为什么计划总坚持不下去。

但这类聊天很容易出问题：换一家 AI，结论可能就变；你知道“背景很重要”，却不知道该告诉它什么；聊久了，AI 还可能把一次判断当成“你就是这种人”；隔阵子回来，又得重新解释前情。

这个 Skill 很复古：没有程序、脚本或评分模型，就是一套写给 Agent 的 Prompt 规则。

## 先说它不做什么

它不是心理咨询，不做心理诊断和人格分析；不预测未来，不算命、不占卜。它也不扮演一味顺着你、最后推销某个“最适合你答案”的 AI 好朋友。

可以回答“现在还不知道”，也可以指出“你可能问错问题了”。

## 如果非要用四个人来形容它

这套机制其实可以很直观地记成：

> **苏格拉底负责问，福尔摩斯负责查，富兰克林负责试，张良负责判断什么时候该做什么。**

这只是一个方便理解的比喻，不是让 AI 去模仿四个人的人格。

**苏格拉底**代表的是：先别急着回答，看看问题本身是不是问对了，还有哪些前提其实没有成立。

**福尔摩斯**代表的是：别什么都靠用户自我分析。现实里能查的去查，过去真实发生过什么就看证据。

**富兰克林**代表的是：有些事情想一百遍也不知道。既然如此，就设计一个成本不高、可以反悔的小实验，做完再判断。

**张良**代表的是最后的研判：什么变量才真正重要，什么时候信息已经够了，什么时候应该继续查，什么时候该停下来行动。

所以它不是只有“会提问”这一招，而是在几种方式之间不断切换：

> **该问就问，该查就查，该试就试，最后判断现在究竟该继续想，还是该做了。**

## 它怎么聊

它没有固定问卷，也不会为了“更了解你”无限追问。每得到一条新信息，都会重新判断：**现在最值得弄清的未知是什么？什么答案真的可能改变判断？**

然后选最合适的办法：

- **ASK**：问只有你知道的事；
- **RESEARCH**：查价格、规则、机构、当地资源；
- **INSPECT**：看你过去真实做过什么，而不是问“你是不是自律的人”；
- **INFER**：根据证据提出暂时解释，不把猜测写成事实；
- **TEST**：靠想象答不了，就设计一次现实尝试。

它不是“问满 20 题 → 算分 → 给答案”，而是边聊边更新，问题应该越来越少、更关键。

## 不用每次从头交代

长期话题可以保留关键背景、未解决的问题和当前判断。以后回来，可以从上次停下的位置继续。

但这些历史不会自动变成“人格档案”。事实会过期，偏好看场景，旧推断也可能被推翻；过去的信息只在当前问题相关时才会参考。

## 它也应该知道什么时候闭嘴

如果下一题无论怎么答都不会改变建议，就别问了；能查的去查；只有亲自体验才知道的，就去试。

目标不是把你分析透，而是推进到：**已经足够知道下一步该做什么。**
